# Task: Student Registration Page (plain HTML only, no CSS or JS)

Create a file called `registration.html` that contains the following.

## 1. A registration form

The form must have these fields and validation rules:

- **Full name:** required, 3-30 characters, and it should have `autofocus`.
- **Email:** required, and it must be a valid email address.
- **Phone:** required, exactly 10 digits (use `pattern` and `title`).
- **Age:** a number between 16 and 40.
- **Date of birth:** required, with a `min` and `max` date.
- **Course:** a dropdown, required (the first option must have an empty value).
- **Agreement checkbox:** "I accept the rules", required.
- **A Submit button.**

## 2. An inline SVG

Place an inline SVG below the form, such as a simple logo, drawn with at least one rectangle, one circle and one line.
