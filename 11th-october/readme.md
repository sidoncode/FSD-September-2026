# Student Task: Make a Web Page About Yourself

Make a one-page web page about yourself using HTML and CSS in VS Code.

## Your page needs

- A header with your name
- A menu with three links: About, Hobbies, Contact
- An About box with a short text and a picture
- A Hobbies box with a list of four hobbies
- A Contact box with your email and a button
- A footer

## Style it with CSS

- Link a `style.css` file
- Add one inline style
- Add one small `<style>` tag
- Use different selectors: tag, class, ID, hover, and a combinator like `nav a`
- Use colors in hex, rgb and hsl, with CSS variables
- Give the header a gradient
- Give one box a background picture
- Add two Google Fonts
- Size text with `rem` and `%`
- Center the header text and the menu links
- Add comments in your code

## Marks

- Total: 50 marks
