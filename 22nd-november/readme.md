

# TypeScript – Functions Practice Assignment

## Instructions

1. Create a file named `functions.ts`.
2. Write your solutions using TypeScript.
3. Use appropriate function parameters and return types.
4. Compile the TypeScript file:

   ```bash
   tsc functions.ts
   ```

5. Run the generated JavaScript file:

   ```bash
   node functions.js
   ```

---

## Practice Assignments

| No. | Assignment | Concept |
|---|---|---|
| 1 | Create a function to add two numbers. | Function declaration |
| 2 | Create a function to check whether a number is even or odd. | Parameters and return |
| 3 | Create a function to calculate simple interest. | Multiple parameters |
| 4 | Create a function to greet a user. Use `Student` as the default name. | Default parameters |
| 5 | Create a function to find the largest of two numbers using an arrow function. | Arrow functions |

---

## Expected Output

Your program should display appropriate results for each assignment.

Example:

```text
Addition: 30
Number is Even
Area of Rectangle: 200
Simple Interest: 500
Hello Student
Employee Salary: 35000
Largest Number: 80
```

## Optional Challenge

Create a simple calculator using separate functions for:

2. Subtraction
3. Multiplication
