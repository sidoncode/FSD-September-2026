# CSS Student Problems: Variables, Glass Cards and Keyframes

## Problem 1: CSS Variables

Create a page with a colorful background and a rounded card.

- Define two colors and a border radius as CSS variables in `:root`.
- Use them for the background gradient and the card's corners.
- Change only the variables and check that the whole page updates.

## Problem 2: Glass Card

Create a card in the center of a colorful background.

- Make the card semi-transparent.
- Blur the background behind the card.
- Give the card a thin light border.
- Use white text so it is easy to read.

## Problem 3: Keyframe Animation

Animate the glass card so it floats up and down forever.

- Write the motion with `@keyframes`.
- Make one full up-and-down cycle take 3 seconds.
- Use an easing that starts and ends slowly.

## Bonus Challenge

Combine all three problems so the card floats and its colors come from CSS variables.

- Add a second card that uses a different set of variable values.
- Do not copy any colors into the second card.
