
# Student Practical Task: Create a Product Gallery

**Level:** Beginner  
**Duration:** 1hr
**Technologies:** HTML5 and CSS3

## Objective

Create a simple product gallery webpage using HTML and CSS. Display four products in a two-column grid and apply CSS Box Model and Transform effects.

## 1. Task Description

Imagine you are building a small online shopping webpage.

Your webpage must contain:

1. A header with the website name.
2. A heading: **Our Products**.
3. Four product cards.
4. Each card must contain a product image, product name, price and Buy Now button.

## 2. Time Plan

| Activity | Time |
|---|---:|
| Create the HTML structure | 20 minutes |
| Apply CSS Box Model | 10 minutes |
| Create the CSS Grid layout | 10 minutes |
| Apply CSS Transform effects | 10 minutes |
| Test and improve the page | 10 minutes |
| **Total** | **60 minutes** |

## 3. Requirements

### Task 1: HTML Basics

- Create a valid HTML document structure.
- Use headings, paragraphs, images and buttons.
- Create four product cards using `<div>` elements.

### Task 2: CSS Box Model

- Set the product card width and height.
- Apply padding and margin.
- Add borders and rounded corners.
- Apply background colours.

### Task 3: CSS Grid Layout

- Display four products in **two columns**.
- Add spacing between cards using `gap`.
- Align the cards neatly.

### Task 4: CSS Transforms — 2D and 3D

When the user hovers over a product card:

- Increase its size using `scale()`.
- Rotate it using `rotate()`.
- Move it using `translate()`.
- Try a simple 3D effect using `rotateY()` or `rotateX()`.
- Use `perspective()` to make the 3D effect easier to see.

### Task 5: CSS Animations and Keyframes

Add a small animated element to the page, such as a notification dot or a label that says **Special Offer!**

- Define an animation using `@keyframes`.
- Use `0%`, `50%` and `100%` keyframe steps.
- Change at least one property, such as colour, size or position.
- Apply the animation using the `animation` property.

Example idea: make a small offer badge gently grow and shrink continuously.

## 4. Bonus Challenges

Complete these only if you finish early:

- Change the grid to four columns.
- Add `transform: translateY(-10px)` on hover.
- Try `rotateX()` or `rotateY()` for a 3D card effect.
- Change the product card background colour on hover.
- Make the offer badge pulse using keyframes.
- Make the layout display one column on a narrow mobile screen.

## 5. Learning Outcomes

| Topic | What you will practise |
