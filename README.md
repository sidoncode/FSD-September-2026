## How to Use This Repo

1. Clone the repository:
   ```
   git clone https://github.com/sidoncode/FSD-September-2026.git
   ```
2. Open the folder in VS Code.
3. Open any `.html` file in your browser, or use the **Live Server** extension, to see the output.
4. Use the **Content** link in the table to find the code and notes for each class.
5. Use the **Whiteboard** link to review the diagrams drawn during the class.
